Sample Projects
===============

The Thunder Engine project provides several small open-source sample projects that are useful for learning by example. Clone any of them and open the included `.forge` project in Thunder Hub or the editor.

Available samples
-----------------

1. ThunderMine (Minecraft-like)

   Repository: https://github.com/thunder-engine/sample-mine

   Description: A simple educational 3D project demonstrating block interaction, free movement, and basic world mechanics.

   Quick start:

   .. code-block:: bash

      git clone https://github.com/thunder-engine/sample-mine.git
      # Open the project in Thunder Hub or launch WorldEditor and open `mine.forge`
   
   .. image:: media/sample-mine.png
      :alt: ThunderMine screenshot
      :width: 320px

2. Thunder 2048 (2048 puzzle)

   Repository: https://github.com/thunder-engine/sample-2048

   Description: A 2048-style puzzle game demonstrating 2D grid handling, input, and game state management.

   Quick start:

   .. code-block:: bash

      git clone https://github.com/thunder-engine/sample-2048.git
      # Open the project in Thunder Hub or launch WorldEditor and open `2048.forge`
   
   .. image:: media/sample-2048.png
      :alt: Thunder 2048 screenshot
      :width: 320px

3. Flappy (endless runner)

   Repository: https://github.com/thunder-engine/sample-flappy

   Description: A small 2D Flappy-style example showing simple physics, scoring and input handling.

   Quick start:

   .. code-block:: bash

      git clone https://github.com/thunder-engine/sample-flappy.git
      # Open in Thunder Hub or launch WorldEditor and open the provided project file

Notes
-----

- For best experience, use Thunder Hub to register the project and select a compatible engine install (see :doc:`thunder_hub`).
- Check each repository README for project-specific prerequisites and controls.
